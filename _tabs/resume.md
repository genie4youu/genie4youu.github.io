## 논문 및 특허

### 논문

**1) Real-Time Gait-Adaptive Acceleration Control for Natural Overground Walking on Interactive Treadmills**<br>
대한기계학회(KSME), 2025.05

- **적응형 속도 제어 (Souman 기반):** 보행자의 위치와 속도 오차, 이동 추세에 따라 제어기 파라미터를 실시간 갱신하는 adaptive controller 설계. 프로젝션, 데드존, 레이트 리미터로 게인 변화를 안전 범위로 제한하여 급복귀와 오버슈트를 억제하고 중심 유지 성능을 높임
- **순간 속도 변화 완화 (예측과 감쇠):** 사용자 연결 케이블의 장력 변화를 AR(Autoregressive) 시계열 예측으로 다음 구간의 속도 요구를 추정하고, attenuator 로 속도를 부드럽게 이행

**2) Toward a Customizable Body Weight Support System with Interactive Treadmill for Patients with diverse gait impairments**<br>
IEEE International Conference on Rehabilitation Robotics (ICORR) 2025, 2025.05

- **Fuzzy Logic 기반 보조력 제어:** 사용자의 움직임에 따라 보조력이 자동 조절되는 Assist-as-needed 알고리즘 설계, Rule-base 추론으로 실시간 제어 수행
- **보행 상태 추정 및 지표 산출:** IMU, 로드셀, 엔코더 데이터를 통합하여 보행 상태와 사용자 협응도를 실시간 추정, 개인 맞춤형 보조값 계산

## 자기소개서

### 지원 동기

저는 로봇 제어 시스템을 전장부터 미들웨어, 알고리즘, HMI까지 한 흐름으로 설계하고 현장에서 검증해 온 엔지니어입니다. 로봇 제어 소프트웨어와 로봇 소프트웨어 플랫폼을 통해 현장의 자동화를 실현하는 방향은, 제가 석사 과정에서 쌓아 온 실시간 로봇 제어 역량을 확장할 수 있는 환경이라 판단했습니다.

석사 과정에서 사용자 상호작용 기반 모션제어 시스템을 연구하며, 로봇공학 수업에서 학습한 키네마틱스(FK/IK/Velocity Kinematics)와 3D 좌표 변환 이론, 그리고 EtherCAT 기반 모터 제어, ROS 2 미들웨어 설계, Qt HMI 구현까지 로봇 소프트웨어 개발의 전 과정을 경험했습니다. 특히 제 연구에서 다룬 센서 데이터 기반 환경 예측과 실시간 모터 제어는 로봇 경로/모션 계획의 하위 계층과 문제 구조가 같아, 즉시 기여할 수 있는 영역이라고 생각합니다.

입사 후에는 기존 로봇 제어 소프트웨어의 구조와 통신 흐름을 파악한 뒤, 실시간 제어 루프 최적화와 모션 프로파일 튜닝으로 사이클타임과 위치 정밀도 개선에 기여하겠습니다. 운용 현장에서는 로깅/리플레이 기반 디버깅 경험을 활용해 이슈 대응 속도를 높이겠습니다.

### 준비된 직무 역량

해당 직무에 필요한 핵심 역량은 첫째, 로봇 상위 제어를 위한 실시간 시스템 구현 능력입니다. 둘째, 로봇 소프트웨어 플랫폼을 설계하고 유지보수하는 아키텍처 역량입니다. 셋째, 운용 현장에서 발생하는 이슈를 빠르게 진단하고 대응하는 실무 문제 해결력이라고 생각합니다.

저는 석사 연구에서 Linux PREEMPT-RT 환경의 C++ 기반 고정 주기 제어 루프를 설계하여 1kHz에서 제어 주기 98.2% on-time을 달성했습니다. SCHED_FIFO를 적용한 실시간 스케줄링과 EtherCAT 통신 기반 모터의 위치/속도 제어를 PDO 동기 매핑으로 구현하여, 로봇 상위 제어에 직접 전이 가능한 실시간 제어 역량을 갖추고 있습니다.

로봇 소프트웨어 플랫폼 측면에서는 ROS 2 기반 3노드 미들웨어를 설계하여 실시간 제어, 데이터 분석, HMI를 독립 프로세스로 분리했습니다. Qt Creator로 운영자 화면을 직접 구현하여 상태 모니터링, 데이터 로깅, 파라미터 튜닝을 통합했습니다.

현장 이슈 대응 역량으로는 15명 대상 현장 검증을 운영하며, 실시간 로깅과 리플레이 기반 검증 체계를 구축하여 이상 상황을 재현하고 원인을 추적하는 디버깅 프로세스를 경험했습니다. E-stop, fail-safe, 속도/가속도 한계를 포함한 3계층 안전 로직을 설계하여 사용자 안전을 보장하며 시스템을 운영했습니다.

### 차별화된 강점과 약점

저의 차별화된 강점은 '실시간 로봇 제어 시스템 전 계층을 직접 구축해 본 경험'입니다. 전장 설계부터 이종 통신 통합(EtherCAT/CAN/Serial), 미들웨어 아키텍처, 제어 알고리즘, 안전 로직, HMI까지 한 흐름으로 연결하여 시스템을 완성한 경험이 있습니다. 이를 통해 단일 계층이 아닌 시스템 전체의 동작을 이해하고 최적화하는 시야를 갖추게 되었습니다.

두 번째 강점은 적응형 제어 알고리즘을 직접 설계하고 현장에서 검증한 경험입니다. 사용자 동작 상태에 따라 제어 파라미터를 실시간으로 갱신하는 게인 스케줄링을 설계하여 추종 성능 84% 향상을 달성했고, AR 기반 시계열 예측과 감쇠기 적용으로 과도 응답 가속도를 50% 이상 억제했습니다. 이론에서 구현, 현장 검증까지 완결한 이 경험은 로봇 모션 제어의 정밀도와 안정성을 높이는 데 직접 기여할 수 있다고 판단합니다.

반면 보완해야 할 약점은 산업용/협동 매니퓰레이터를 직접 운용하며 경로 계획과 모션 계획을 구현해 본 경험이 부족하다는 점입니다. 석사 과정에서 로봇 키네마틱스(FK/IK/Velocity)와 3D 좌표계 변환 이론을 학습했고, EtherCAT 기반 모터 제어시스템을 직접 구현한 경험이 있어 로봇 제어의 이론적/실무적 기반은 갖추고 있습니다. 이후 개인 프로젝트로 이동 로봇의 전역 경로 계획과 지역 경로 계획을 직접 구현하며 계획 계층을 다뤄 왔습니다. 입사 후에는 이 기반 위에 매니퓰레이터 경로/모션 계획 실무를 빠르게 습득하여, 실시간 제어 역량과 결합한 로봇 상위 제어 전문가로 성장하겠습니다.
