무엇을 붙일지는 [08. MCP, 로컬 도구를 붙인다](/posts/08-mcp/) 에, 프로토콜과 MATLAB 연결은 [MCP와 MATLAB 연결](/posts/00-mcp-series/) 시리즈에 있다. 여기서는 붙이고, 확인하고, 떼는 순서만 다룬다.

## 1. 붙이기 전에 본다

| 질문 | 볼 것 |
| --- | --- |
| 누가 만들었나 | 제작사 공식인가 3자인가. `@latest` 같은 패키지는 버전을 고정한다 |
| 무엇을 실행하나 | stdio 면 실행 파일, 인자, 환경변수. 이 프로세스는 샌드박스 밖에서 돈다 |
| 무엇을 할 수 있나 | 쓰기, 보내기, 공유, 코드 실행 도구를 골라 둔다. 외부 콘텐츠를 가져오는 서버는 프롬프트 인젝션 통로다 |
| 얼마나 드나 | tool search 가 기본이라 도구 정의는 필요할 때 실린다. 결과 상한은 기본 25,000 토큰 |

MCP 스펙도 도구를 임의 코드 실행으로 본다.

## 2. 범위 — 어디에 적히나

| 범위 | 적히는 곳 | 누가 보나 |
| --- | --- | --- |
| local (기본) | `~/.claude.json` 의 그 프로젝트 항목 | 나, 이 프로젝트 |
| project | 저장소 루트 `.mcp.json` | 협업자 전원. 각자 처음에 승인 |
| user | `~/.claude.json` | 나, 모든 프로젝트 |
| plugin 동봉 | plugin 의 `.mcp.json` | plugin 이 켜진 곳 |
| claude.ai 커넥터 | 계정 설정 | 그 계정 세션 |

같은 이름이 여러 곳에 있으면 표의 위쪽 하나를 통째로 쓴다. Codex 는 `~/.codex/config.toml` 에 적으므로 두 도구에서 쓰려면 양쪽에 등록한다.

## 3. 등록 명령

stdio 는 `--` 앞이 Claude Code 옵션이고 뒤는 서버 명령 그대로다.

```bash
claude mcp add --env KEY=value --transport stdio --scope user <이름> -- <실행파일> [인자...]
claude mcp add --transport http --scope user <이름> https://example.com/mcp
codex mcp add <이름> --env KEY=value -- <실행파일> [인자...]
```

`--env` 바로 뒤에 이름이 오면 이름까지 `KEY=value` 로 읽고 거부하므로 사이에 다른 옵션을 둔다. JSON 으로 적을 때 `url` 항목에 `"type"` 이 없으면 그 서버를 건너뛴다.

## 4. 비밀은 환경변수로

설정에는 변수 이름만 두고 값은 환경에 둔다. 커밋되는 `.mcp.json` 은 특히 그렇다.

| 무엇 | Claude Code | Codex |
| --- | --- | --- |
| 원격 로그인 | `/mcp` 또는 `claude mcp login <이름>` | `codex mcp login <이름>` |
| 토큰과 키 | `.mcp.json` 에 `${VAR}`, `${VAR:-기본값}` | `bearer_token_env_var`, `env_http_headers` |

정의되지 않은 변수에 기본값도 없으면 `${VAR}` 글자가 그대로 들어가고 `mcp list` 에 경고가 뜬다.

## 5. 승인 규칙

읽기는 통과시키고 쓰기, 보내기, 실행만 묻게 한다. Claude Code 권한 규칙의 MCP 표기는 glob 이다.

```jsonc
// ~/.claude/settings.json
{ "permissions": {
    "allow": ["mcp__<서버>__*"],          // 서버 전체. mcp__<서버> 와 같다
    "ask":   ["mcp__<서버>__<쓰기도구>"] } }
```

서버 자리를 비운 `"mcp__*"` allow 는 무시된다. hook matcher 는 `.` 같은 글자가 있어야 정규식으로 읽으므로 서버 전체를 `mcp__<서버>__.*` 로 쓴다. `mcp__<서버>` 만 쓰면 정확 일치로 읽혀 어떤 도구에도 맞지 않는다.

```toml
# ~/.codex/config.toml
[mcp_servers.<이름>]
command = "<실행파일>"
tool_timeout_sec = 600                  # 기본 60. 긴 MATLAB 작업에는 짧았다
default_tools_approval_mode = "prompt"  # auto, prompt, writes, approve
```

도구별로는 `[mcp_servers.<이름>.tools.<도구>]` 에 `approval_mode` 를 둔다. `approve` 는 묻지 않고 통과시키는 값이라([16편](/posts/16-mcp-config-applied/)) 묻게 하려면 `prompt` 를 쓴다.

## 6. 켜졌는지 확인

| 명령 | 보이는 것 |
| --- | --- |
| `claude mcp list` | `✔ Connected`, `! Needs authentication`, `✘ Failed to connect`, `⏸ Pending approval` |
| `claude mcp get <이름>` | 그 서버 하나의 설정 |
| `/mcp` | 세션 안의 상태, 인증, 켜고 끄기 |
| `/context` | `mcp__<서버>__<도구>`, tool search 면 `(deferred)` |

Codex 는 `codex mcp list` 와 `/mcp` 로 본다. `Connected` 는 붙었다는 뜻일 뿐이라 실제로 한 번 불러 본다. 전체 이름이 128자를 넘는 도구는 Claude 에 보내지 않는다.

## 7. 끄기와 되돌리기

| 하고 싶은 것 | Claude Code | Codex |
| --- | --- | --- |
| 이 프로젝트에서만 끄기 | `/mcp` 에서 끈다 | `enabled = false` |
| 도구 일부만 막기 | `permissions.deny` 에 도구 이름 | `disabled_tools` |
| 제거 | `claude mcp logout` 후 `remove` | 그 표를 지운다 |
| `.mcp.json` 승인 되돌리기 | `claude mcp reset-project-choices` | |

remove 만으로는 발급한 쪽의 토큰이 회수되지 않는다.

## 8. 겪은 것

| 관측 | 대응 |
| --- | --- |
| 메일, 파일 커넥터의 보내기와 공유 도구는 데이터를 밖으로 내보내는데 로컬 설정 파일에는 보이지 않는다 | 그 도구만 `ask` 에 넣는다 (`mcp__claude_ai_<서버>__<도구>`) |
| 같은 서버인데 Codex 에만 승인 규칙이 있었다 | 두 도구의 승인을 맞춘다 |
| 3자 서버에 고친 패치가 재설치 때 사라졌다 | 재적용 스크립트를 둔다 |
| `claude -p` 는 `.mcp.json` 서버를 묻지 않고 로드한다 | 헤드리스는 `--strict-mcp-config` 와 `--mcp-config` 로 쓸 서버만 준다 |
