# genie4youu.github.io

로봇 제어 소프트웨어 공부 기록. [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마 기반 Jekyll 사이트.

**사이트** → <https://genie4youu.github.io>
**시리즈 목록** → <https://genie4youu.github.io/series/>

편수와 시리즈 수는 여기 안 적는다. 손으로 적으면 글이 늘 때마다 조용히 낡는다. 위 시리즈 페이지가 `_posts/` 를 직접 세서 보여준다.

---

## 이 저장소만의 규칙

Chirpy 문서에 없고 여기서 겪어서 정한 것들이다. 어기면 조용히 깨진다.

### 1. `_data/series.yml` 이 시리즈의 단일 정본이다

카드 이름, 아이콘, 소개, 어느 폴더를 묶는지가 전부 여기 있다. 카드를 고치려면 `_layouts/landing.html` 이 아니라 이 파일을 고친다.

- **편수는 이 파일에 적지 않는다.** `landing.html` 과 `_tabs/series.md` 가 `_posts/<dir>/` 를 직접 센다
- **00 목차 글은 편수에서 뺀다.** 세면 카드는 "23편" 인데 그 카드를 눌러 들어간 목차 글 본문은 "22편으로 정리한다" 가 되어 같은 시리즈에 두 숫자가 뜬다
- **카드를 늘릴 때 `assets/css/jekyll-theme-chirpy.scss` 의 색 맵도 같이 늘린다.** 카드 `id` 와 색 키 이름이 같아야 한다
- 🔴 **`index:` 가 가리키는 글이 실재해야 한다.** 없는 글을 가리키면 htmlproofer 가 internal-link 실패를 내고 배포가 통째로 떨어진다 (2026-08-07 에 실제로 겪었다)
- **`index:` 는 시리즈에만 둔다.** 서로 이어지지 않는 글이 섞이는 칸(업계 읽기, 쉬어가기)은 `category:` 로 카테고리 페이지에 보낸다. 그런 칸에서 어느 한 편을 `index` 로 두면 **그것이 칸의 전부인 것처럼 보이고** 새 글은 카드를 눌러도 안 나온다
- **`top_category:` 는 링크가 아니라 대응 기록이다.** 그 연재 글들이 실제로 쓰는 `categories:` 첫 칸을 적는다. `name` 과 다를 수 있고 **다른 것이 정상이다** — 아래 규칙 5
- **`resume_note:` 는 `_tabs/resume.md` 블로그 표의 한 줄이다.** 그 표는 이 파일을 순회해 만든다. 비면 이력서에 빈칸이 나간다

### 2. 탭 제목은 frontmatter 가 아니라 `_data/locales/ko-KR.yml` 이 정한다

`_tabs/*.md` 에 한글 `title:` 을 넣으면 사이드바에는 나오는데 `<title>` 태그가 빈다. 파일명과 같은 키로 로케일 파일에 적는다.

### 3. 탭 파일은 BOM 없이 저장한다

BOM 이 있으면 그 탭이 통째로 안 만들어진다.

### 4. 볼트가 원본이고 이 저장소는 사본이다

글은 볼트에서 쓰고 여기로 복사한다. 복사할 때 `publish:` 와 `sources:` 두 필드를 뺀다. **그 둘 말고 다른 필드도 본문도 양쪽이 같아야 한다.**

한쪽만 고치면 다음 개정 때 다른 쪽이 덮어써서 조용히 되돌아간다. 2026-08-24 에 `categories:` 57편이 이렇게 어긋나 있던 것을 발견해 맞췄고, **2026-08-25 에 본문까지 갈라진 10편을 또 찾았다** — 표현 치환 5편, 시리즈 사슬 수리 3편, 목차 글 본문 2편이 전부 저장소에만 반영돼 있었다. 볼트 `stateflow/00` 은 23편짜리 연재를 "13편"이라 적고 있었다.

**예외 — 원본이 볼트 다른 곳에 있는 것 (규칙 4가 적용되지 않는다)**

| 저장소 | 원본 | 왜 |
| --- | --- | --- |
| `_posts/etc/` | `portfolio/기타/` | 학습 시리즈가 아니라 폴더가 다르다. 대응은 1:1 이다 |
| `_posts/news/` `papers/` `trends/` | `study/news/` `study/papers/` `study/trends/` | `/trendpub` 이 **파일명 규격을 바꿔** 내보낸다(`2026-W34_논문_….md` → `paper-….md`). 파일 단위 대조가 성립하지 않는다 |

⚠️ **이 24편을 「드리프트」로 판정하고 `portfolio/blog/` 에 사본을 만들지 마라.** 원본이 둘이 된다.

### 5. 이름은 자리마다 역할이 다르다 — 맞추려 하지 마라

`top_category`(대분류)는 **주제 영역**이고 `name`(카드)은 **연재 제목**이다. 5건이 일부러 다르다.

| 카드 `name` | `top_category` | 왜 다른가 |
| --- | --- | --- |
| ADRC | 제어 이론 | 앞으로 다른 제어 연재가 같은 칸에 들어온다 |
| MCP와 MATLAB 연결 | AI 에이전트 | 위와 같다 |
| MATLAB과 Simulink 문법 | MATLAB과 Simulink | 문법편은 그 주제의 일부다 |
| 실내 배송 AMR | AMR | 다른 AMR 글이 들어올 자리다 |
| Stateflow 레이아웃 자동화 | Stateflow | **카드는 둘인데 주제는 하나다.** 소분류로 갈린다 — 이쪽이 `레이아웃 자동화`, `stateflow/` 의 API·User's Guide 2편이 `자동화` |

대신 **같아야 하는 곳이 셋 있다**: `series.yml` 의 `name` = `_tabs/series.md` 의 절 제목 = `00` 목차 글 제목. 검사 8이 본다.

### 6. 번호는 「이어지는 글」에만 붙인다

- **폴더 하나가 연재의 한 구간**이고 번호는 **구간마다 `01` 부터 다시 시작한다.** 연재 전체 통번호가 아니다. 로봇 통신 84편은 7구간, RTOS 42편은 3구간, MATLAB과 Simulink 22편은 3구간이라 `01.` 로 시작하는 글이 여럿이다 — 정상이다
- **`00` 은 그 구간의 지도**다. 보통 시리즈 목차이고, `comm-ethercat/00-ethercat-overview` 처럼 구간 하나의 지도일 수도 있다
- 🔴 **안 이어지는 글에는 파일명에도 제목에도 번호를 붙이지 않는다.** 번호가 있으면 읽는 사람은 앞 편을 찾는다. 2026-08-25 에 `03-arm7-eleven-oclock-number` 를 `arm7-eleven-oclock-number` 로 고쳤다 — 앞 2부작과 이어지지 않는 단편이었다
- 🔴 **파일명 번호와 제목 번호는 양방향으로 같아야 한다.** 둘 다 있고 값이 같거나, 둘 다 없거나. 검사 9가 본다

### 7. 목차 글 제목은 한 형식이다

```
00. <series.yml 의 name> — 시리즈 목차
```

괄호 부연은 붙여도 된다(`00. ADRC(외란 관측 기반 제어) — 시리즈 목차`). 2026-08-25 이전에는 **6가지 형식이 섞여** 있었다(`00. 목차: X` / `X 연재 목차` / `X (목차)` / 목차라는 말이 아예 없는 것). 목록·검색에서 시리즈 이름이 **앞에** 와야 12편이 서로 구분된다.

`목차` 소분류에 12편이 섞이는 것은 **의도다.** 전 시리즈의 입구 모음으로 쓰고 `_tabs/series.md` 가 링크한다. 편수 계산 Liquid 도 `categories contains '목차'` 로 `00` 글을 걸러내므로 **이름을 시리즈별로 쪼개면 그쪽이 깨진다.**

### 8. 흐름 콘텐츠 파일명은 지금 그대로 둔다

`news/2026-07-27-news-20260727.md` 는 날짜가 두 번인 것처럼 보이는데, 앞은 **Jekyll 이 요구하는 날짜 접두사**이고 뒤가 slug 다. `papers/` 의 `paper-` 와 `book-` 은 종류가 실제로 둘이라 그렇다. 둘 다 결함이 아니므로 개명하지 않는다.

## 발행 전 검사

```bash
node tools/lint-site.mjs
```

열 가지를 본다. 1~5 는 2026-08-24, 6~10 은 2026-08-25 에 붙였다. **전부 이미 한 번씩 실제로 일어난 것들이다.**

| # | 검사 | 왜 |
| --- | --- | --- |
| 1 | 태그 슬러그 충돌 | Jekyll 이 대소문자를 접는다. `EtherCAT` 과 `ethercat` 이 한 페이지가 되면서 표기가 불안정해진다 |
| 2 | 위키링크 잔존 | 볼트에서 옮길 때 `[[...]]` 를 안 걷으면 깨진 글자로 나온다 |
| 3 | 내부 링크 실재 | CI 가 최종적으로 잡지만 push 전에 알면 왕복이 준다 |
| 4 | frontmatter | 필수 필드 누락, 그리고 볼트 전용 필드가 딸려 왔는지 |
| 5 | mermaid 플래그 | 플래그가 없으면 그림이 통째로 코드 블록으로 나온다 |
| 6 | 시리즈 목차 커버리지 | `index:` 가 실재하는가 + 그 목차가 카드 `dirs` 안 글을 전부 링크하는가. 🔴 판정 단위는 `index:` 라서 **`index` 없는 카드는 자동으로 대상 밖**이다 — 예외 목록이 필요 없다 |
| 7 | 소분류 충돌 | `/categories/<소분류>/` 는 대분류를 안 가리므로 한 페이지에 섞인다. `목차` 만 명시 예외 |
| 8 | 시리즈 이름 일치 | 카드 `name` = 절 제목 = `00` 목차 글 제목, 그리고 `top_category` 가 실제 대분류와 맞는가. `resume_note` 누락도 본다 |
| 9 | 제목 번호 = 파일명 번호 | 🔴 **양방향**이다. 한 방향만 보면 「파일명엔 번호, 제목엔 없음」을 못 잡는다 |
| 10 | 폴더 안 번호 연속성 | 결번과 중복 |

**이 스크립트는 금칙어 검사를 안 한다.** 그 목록은 이 저장소에 없고 있어서도 안 된다. 볼트 쪽에서 따로 돈다.
**볼트↔저장소 대조도 안 한다.** 볼트 경로를 공개 저장소에 박게 되기 때문이다. 볼트 쪽 `.claude/scripts/blog-drift.ps1` 이 한다.

⚠️ 오탐이 나면 항목을 고친다. 경고가 잦으면 사람이 이 스크립트를 무시하게 되고, 그때 검사가 죽는다.

🔴 **검사를 새로 붙이면 일부러 결함을 심어 실제로 실패를 내는지 확인한다.** 통과만 하고 실패를 못 내는 검사기는 검사기가 아니다. 6~10 은 붙일 때 5종 전부 확인했다.

## 배포

`main` 에 push 하면 `.github/workflows/pages-deploy.yml` 이 돈다.

```
build → Test site (htmlproofer) → deploy
```

세 단계가 다 통과해야 발행이 끝난 것이다. `Test site` 가 내부 링크를 전수 검사하므로 여기서 떨어지면 링크 문제다.

```bash
gh run watch <run-id> --exit-status
```

Liquid 를 고쳤으면 **반드시 빌드를 지켜본다.** 로컬에 ruby 와 bundler 가 없으면 순회 문법이 실제로 도는지는 빌드에서만 확인된다.

## 구조

| 경로 | 무엇 |
| --- | --- |
| `_posts/<시리즈>/` | 글. 폴더는 사람이 찾기 쉬우라고 나눈 것이고 URL 에는 영향이 없다 |
| `_data/series.yml` | 시리즈 카드 정본 |
| `_tabs/` | 고정 페이지 (시리즈, 이력, 소개, 아카이브, 카테고리, 태그) |
| `_layouts/landing.html` | 홈. 시리즈 카드와 최근 글을 `series.yml` 에서 도출한다 |
| `tools/lint-site.mjs` | 발행 전 검사 |

`_posts/` 하위 폴더는 URL 에 영향을 주지 않는다. permalink 는 `/posts/<slug>/` 그대로이고, 사이트에서의 분류는 `categories:` 가 한다. 둘 다 맞춰야 의미가 있다.
