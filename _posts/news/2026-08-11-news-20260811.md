하루 사이에 큰 숫자가 두 개 나왔다. 미국에서는 자동화 공장 운영사 Hadrian이 13.7억 달러를 받아 78.7억 달러 밸류에이션이 됐고, 중국에서는 Unitree 상하이 청약에 8,000억 위안이 묶여 당첨률이 0.018%까지 내려갔다. 둘 다 로보틱스로 흘러든 자금인데 값을 매기는 대상이 다르다. 앞쪽은 로봇이 만들어낸 부품에 값을 매기고, 뒤쪽은 로봇 자체에 값을 매긴다.

## Hadrian, 13.7억 달러 조달로 밸류에이션 78.7억 달러

Hadrian Automation이 8월 10일 13.7억 달러 지분 투자를 발표했다. 2020년 설립된 캘리포니아 토런스 기반 회사로, 항공우주와 방산 정밀부품을 자체 자동화 공장에서 생산한다.

| 항목 | 값 |
| --- | --- |
| 조달액 | 13.7억 달러 (지분 투자) |
| 밸류에이션 | 78.7억 달러 |
| 공동 주도 | WCM Investment Management, Washington Harbour Partners, Valor Equity Partners, 137 Ventures, Baillie Gifford |
| 앵커 공동주도 | JPMorganChase 전략투자그룹 |
| 참여 | Andreessen Horowitz, Founders Fund, Lux Capital, T. Rowe Price, CapitalG |
| 시설 | 토런스, 애리조나 메사, 앨라배마 머슬숄스 4개소 약 279,000 m² (300만 sq ft) |
| 생산 자율화 스택 | 자체 소프트웨어 Opus |
| 자금 용처 | 신규 공장 건설, 생산 라인 확장, 탄약·자율 시스템으로 품목 확대 |

로봇을 파는 회사가 아니라 로봇으로 부품을 파는 회사에 이 규모가 들어갔다는 점에서 다른 라운드와 구분된다. 휴머노이드 쪽 대형 라운드는 대부분 로봇 자체에 값을 매기지만, Hadrian은 자동화를 원가 구조로 쓰고 최종 산출물인 부품값을 받는다. 자동화의 수익 모델이 장비 판매에서 공정 결과 판매로 옮겨가는 흐름 위에 있고, 수요처는 방산이다.

제어 쪽에서 보면 항공우주 정밀부품은 공차가 좁고 로트마다 검증 기록을 남겨야 한다. 사람이 붙는 공정을 줄이면서 그 재현성을 유지하려면 제어 파라미터와 공정 조건을 문서로 고정하고 이력을 남기는 작업이 자동화 자체만큼 비중을 차지한다.

## Unitree 청약 8,288배 초과, 당첨률 0.018%

[공모가가 610억 위안 기업가치로 확정된](/posts/news-20260807/) 뒤 진행된 청약 결과가 나왔다.

| 항목 | 값 |
| --- | --- |
| 온라인 초과청약 배수 | 8,288.82배 |
| 유효 청약 계좌 | 978만 개 |
| 유효 청약 주식 | 536.4억 주 |
| 묶인 자금 | 8,000억 위안 (약 1,188억 달러) |
| 회수 발동 후 온라인 발행 물량 | 970.7만 주 |
| 최종 당첨률 | 0.01809759% |
| 납입 마감 | 2026-08-12 |
| 상장일 | 2026-08-19 |

초과청약 규모가 커서 회수(clawback) 장치가 발동해 온라인 발행 물량이 970.7만 주로 조정됐다. 청약 직전 증권사 추산치는 0.02~0.03%였는데 실제 당첨률은 그보다 낮게 찍혔다.

배수만 보면 감이 잘 안 오므로 비교 대상을 붙인다. 반도체 CXMT(창신메모리) 청약 당첨률이 0.47%였으니 이번은 그 26분의 1이다. 다만 배수보다 묶인 돈의 절대 규모가 이 발표의 내용이다. 8,000억 위안은 상장사 하나의 신주 청약에 중국 개인 자금이 얼마나 몰릴 수 있는지를 보여주는 수치이고, 이만한 자금이 실적이 아니라 상장 첫날 상승률 기대에 반응하고 있다. Unitree 상반기 매출 성장률은 40%대로 둔화된 상태다.

8월 19일 상장일이 이 기대의 첫 채점표가 된다. 같은 날 베이징에서 세계로봇대회(WRC 2026)가 개막한다.

## Tate, 협동로봇 용접기 58대 전사 배치 완료

데이터센터용 구조 천장과 격납 설비를 만드는 120년 된 제조사 Tate가 Hirebotics 로봇 용접 시스템 58대 배치를 마쳤다. 2023년 9월에 시작해 2026년 8월에 전사 확대가 끝났다.

| 항목 | 값 |
| --- | --- |
| 도입 대수 | 58대 |
| 공장 | 아칸소, 버지니아, 켄터키 3개소 |
| 기간 | 2023-09 ~ 2026-08 |
| 로봇 형태 | 힘·출력 제한 협동로봇 팔 |
| 제어 플랫폼 | Beacon Pro, 스마트폰·태블릿 기반 노코드 프로그래밍과 모니터링 |
| 교육 시간 | 1인당 10~20분 |
| 결과 | 구조 조립부 기준 용접기당 처리량 12배, 수작업 편차로 인한 재작업 소멸 |

도입 이유가 인력난 대응이 아니라 데이터센터 수요를 맞추기 위한 증산이었다는 점이 눈에 띈다. 그리고 이건 파일럿 결과가 아니라 3년에 걸친 전사 전환의 완료 보고다. 휴머노이드 투자 라운드 뉴스가 매일 나오는 동안 실제로 공정을 통째로 바꾸고 있는 쪽은 여전히 협동로봇이다. 교육 10~20분과 노코드라는 조건은 통합 업체를 거치지 않고 현장 인력이 직접 돌린다는 뜻이고, 이 진입 장벽 제거가 58대라는 대수를 가능하게 했다.

힘·출력 제한(force- and power-limited)은 ISO/TS 15066이 정의한 협동 운전 4가지 중 하나다. 접촉이 발생해도 인체 부위별 허용 압력과 힘 한계 아래로 유지해 안전 펜스를 없앤다. 별도 안전 영역 감시 장비 없이 배치 밀도를 올릴 수 있는 이유가 여기 있다.

## VicOne, Isaac Sim용 보안 시험 확장을 무료 배포

VicOne이 NVIDIA Isaac Sim용 Radeis Extension을 무료로 공개했다. 로봇 모델을 시뮬레이터에 올린 뒤 공격 시나리오를 걸어 배치 전에 보안 시험을 하는 도구다. 기반이 된 DEF CON 34 Physical AI Safety Stress Test에서는 16개 팀이 25건의 익스플로잇에 성공했고, 취약점이 로봇 스택의 한 층에 머물지 않고 여러 층을 타고 번져 동작을 바꾼다는 결과가 나왔다.

확장이 다루는 공격면은 다섯이다.

1. AI와 비전언어 모델
2. 인지·센서 입력
3. 클라우드·API
4. 로봇 통신 프로토콜
5. 임베디드·펌웨어

로봇 보안이 정보 유출 문제에서 동작 안전 문제로 옮겨온 지점이다. 취약점을 뚫었을 때 나오는 결과가 데이터가 아니라 로봇의 잘못된 움직임이라면 이건 보안 사고가 아니라 안전 사고다. DEF CON 결과의 요지도 계층별로 따로 보면 안 잡히고 시스템 수준에서 봐야 한다는 것이었다.

다섯 공격면 중 아래 둘, 통신 프로토콜과 임베디드·펌웨어가 실시간 제어 계층이다. 필드버스는 대개 폐쇄망을 전제로 설계돼 인증이 약하고, 주기 시간을 지키려고 검증 단계를 줄이는 방향으로 최적화돼 있어 구조적으로 방어가 얇다. 상위 AI 계층을 아무리 검증해도 하위 통신에서 명령이 바뀌면 그 검증은 무효가 된다.

## BYD 샤오디 실물 공개, 판매점 50곳 배치 계획

BYD의 첫 휴머노이드 샤오디(Xiao Di)가 8월 초 정저우 Di Space 센터에서 실물 공개된 것으로 확인됐다.

| 항목 | 값 |
| --- | --- |
| 키 | 1.61 m |
| 무게 | 58.5 kg |
| 자유도 | 31 |
| 통역 | 중국 방언 6종, 외국어 6종 실시간 양방향 |
| 인지 | 360° 시야, 얼굴·입모양·제스처 인식 |
| 초기 배치 | 선전, 상하이 매장 |
| 확대 계획 | 50개 지점, 매장당 2~3대 목표 (Stella Li) |

스펙보다 배치 방식이 이 건의 내용이다. 공장이나 물류가 아니라 자사 판매점에 넣는다. 성능이 못 미쳐도 매출이 걸리지 않으면서 대량 배치로 실사용 데이터를 모을 수 있는 자리다. 자동차 회사가 배터리, 모터, 제어 물량을 이미 갖고 있어 단가에서 순수 로봇 업체보다 유리하다는 계산도 함께 깔려 있다. 다만 지금 공개된 역할은 안내와 통역이고 조작 작업은 보여주지 않았다.

## 흐름으로 볼 것

- 돈이 로봇을 파는 회사와 로봇으로 파는 회사로 갈라지고 있다. Hadrian 13.7억 달러가 후자, Unitree 청약과 휴머노이드 라운드가 전자다. 후자는 제어 성능이 원가와 품질로 곧장 환산되는 구조라 평가 기준이 다르다.
- 협동로봇 쪽에서 전사 전환 완료 사례가 나오기 시작했다. Tate 58대는 파일럿이 아니라 3년 전환의 종료 보고이고, 진입 장벽을 낮춘 것은 팔이 아니라 노코드 제어 플랫폼이었다.
- 로봇 보안이 안전 문제로 재정의되는 중이다. DEF CON 34 결과와 VicOne 도구가 같은 주장을 한다. 공격면 다섯 중 둘이 실시간 제어 계층이고, 이 층은 폐쇄망을 전제로 설계돼 있어 검증 방법론 자체가 아직 정립되지 않았다.
- 8월 12일 Unitree 납입 마감, 8월 19일 상장 겸 WRC 개막이 다음 확인 지점이다.
